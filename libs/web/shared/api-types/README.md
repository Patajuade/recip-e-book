# web-shared-api-types

TypeScript types of the API, generated by [openapi-typescript](https://openapi-ts.dev/) from the OpenAPI document that the API build writes to `apps/api/openapi/RecipEBook.Api.json`.

Don't edit `src/lib/api.ts`: change the API, build it, then regenerate.

```sh
nx run web-shared-api-types:generate         # src/lib/api.ts from the committed OpenAPI document
nx run web-shared-api-types:check-generated  # builds the API, then fails if src/lib/api.ts is out of date (CI)
```

The models libs (`recipes/models`, `shopping/models`) name these types for the rest of the app.
